# Data

- `raw/` – original files exactly as downloaded. Never edited; every run records the SHA-256 of the
  raw file it used.
- `processed/` – generated by `mlpipeline prepare`: cleaned `train.csv` (70%), `val.csv` (15%) and
  `test.csv` (15%) with missing values imputed from the training split only, plus
  `prepare_report.json` (row counts, missing values found, fill values used).

## Dataset card

| Field | Value |
|---|---|
| Name | Auto MPG |
| Source | UCI Machine Learning Repository, derived from the StatLib library (Carnegie Mellon University); used in the 1983 ASA Data Exposition and by Quinlan (1993) |
| Raw files | `raw/auto-mpg.data` (used), `auto-mpg.data-original` (406 rows incl. 8 without `mpg`; unused), `auto-mpg.names` (documentation) |
| Format | Whitespace-delimited, no header row, `?` marks missing values (column names are set in `config.yaml`) |
| Rows / columns | 398 rows, 9 columns (8 predictors incl. 1 identifier, plus the target) |
| Target column | `mpg` (miles per gallon, continuous) |
| Task | Regression |
| Known issues | 6 missing `horsepower` values; small dataset (test split = 60 rows); 1970–1982 vehicles only |

## Data dictionary

| Column | Type | Used as | Description |
|---|---|---|---|
| `mpg` | continuous | target | Fuel economy in miles per gallon |
| `cylinders` | discrete (3–8) | numeric feature | Number of engine cylinders |
| `displacement` | continuous | numeric feature | Engine displacement (cubic inches) |
| `horsepower` | continuous | numeric feature | Engine horsepower; 6 missing values |
| `weight` | continuous | numeric feature | Vehicle weight (lbs) |
| `acceleration` | continuous | numeric feature | Time to accelerate from 0 to 60 mph (seconds) |
| `model_year` | discrete | numeric feature | Model year (70 = 1970 … 82 = 1982) |
| `origin` | discrete (1–3) | categorical feature (one-hot) | Region code: 1 = USA, 2 = Europe, 3 = Japan |
| `car_name` | string | dropped | Unique per row, so an identifier rather than a predictor |
