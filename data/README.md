# Data

- `raw/`: original files, never edited. Each run records the SHA-256 of the raw file used.
- `processed/`: generated by `mlpipeline prepare`: `train.csv` (70%), `val.csv` (15%), `test.csv` (15%),
  imputed from the training split only, plus `prepare_report.json` (row counts, missing values, fill values).

## Dataset card

| Field | Value |
|---|---|
| Name | Auto MPG |
| Source | UCI Machine Learning Repository, from StatLib (Carnegie Mellon University); Quinlan (1993) |
| Files | `raw/auto-mpg.data` (used); `auto-mpg.data-original` (406 rows, 8 without `mpg`; unused); `auto-mpg.names` (docs) |
| Format | Whitespace-delimited, no header, `?` = missing (column names set in `config.yaml`) |
| Size | 398 rows, 9 columns |
| Target / task | `mpg` / regression |
| Known issues | 6 missing `horsepower`; small (60-row test split); 1970–1982 vehicles only |

## Data dictionary

| Column | Type | Used as | Description |
|---|---|---|---|
| `mpg` | continuous | target | Miles per gallon |
| `cylinders` | discrete (3–8) | numeric | Engine cylinders |
| `displacement` | continuous | numeric | Engine displacement (cubic inches) |
| `horsepower` | continuous | numeric | Engine horsepower; 6 missing |
| `weight` | continuous | numeric | Weight (lbs) |
| `acceleration` | continuous | numeric | 0–60 mph time (seconds) |
| `model_year` | discrete | numeric | 70 = 1970 … 82 = 1982 |
| `origin` | discrete (1–3) | categorical (one-hot) | 1 = USA, 2 = Europe, 3 = Japan |
| `car_name` | string | dropped | Unique per row (identifier) |
